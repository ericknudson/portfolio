---
title: User Feedback Digest
summary: >-
  User feedback piled up in forms and spreadsheets, but there was no easy way to see which
  topics were trending or to find user quotes by topic. I built a weekly pipeline that splits
  each submission into individual asks and uses embeddings plus an LLM to match each ask against
  a human-curated list of feature requests. The result was a searchable, ranked view of what
  users want, with real quotes one click away, and a weekly Slack digest that corrects for which
  users are over-represented in the feedback.
